## 1. What SpudBoost does

SpudBoost changes Windows and game settings to try to improve performance: registry values, power plans, services, scheduled tasks, network adapter settings, startup apps, graphics driver profiles and game configuration files. It can also close and lower the priority of other programs, delete temporary files and remove optional Windows apps when you ask it to.

- SpudBoost saves the original value before each change so you can undo it, and can create a Windows restore point. Some actions can't be undone this way, such as deleting junk files and removing apps.
- You choose which changes to make. Read each description before switching something on.
- Results depend on your PC. We don't promise any particular FPS, ping or performance gain.
